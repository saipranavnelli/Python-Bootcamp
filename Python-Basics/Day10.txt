strip()
------
to remove the given charecters from the string object at leading(begening) and trailing(ending) positions.

	strobj.strip(chars)

by default it will remove whitespace charecters.

ex1:
----
>>> x="siva krishna"
>>> x
'siva krishna'
>>> x.strip('s')
'iva krishna'
>>> x
'siva krishna'
>>> x.strip('a')
'siva krishn'
>>> x
'siva krishna'
>>> x.strip('siva')
' krishn'
>>> x
'siva krishna'
>>> x.strip('k')
'siva krishna'
>>> x
'siva krishna'
>>> x.strip('b')
'siva krishna'
>>> x
'siva krishna'

ex2:
----
>>> y="madam"
>>> y
'madam'
>>> y.strip('m')
'ada'
>>> y
'madam'
>>> y.strip('a')
'madam'
>>> y
'madam'
>>> y.strip('am')
'd'
>>> y
'madam'
>>> y.strip('dma')
''
>>> y
'madam'
>>> y.strip('d')
'madam'
>>> y
'madam'

ex3:
----
>>> z=" siva "
>>> z
' siva '
>>> z.strip()
'siva'
>>> z
' siva '

ex4:
----
>>> a="\n \tsiva\n \t"
>>> a
'\n \tsiva\n \t'
>>> a.strip()
'siva'
>>> a
'\n \tsiva\n \t'

split()
-------
Return a list of the substrings in the string, using sep as the separator string.

	strobj.split(sep,maxsplit=-1)

      here sep is the separator used to split the string.

When set to None (the default value), will split on any whitespace character (including \n \r \t \f and spaces) and will discard empty strings from the result.
      
	here maxsplit is the Maximum number of splits,-1 (the default value) means no limit.

    Splitting starts at the front of the string and works to the end.

ex1:
----
>>> x="hello siva krishna good morning"
>>> x
'hello siva krishna good morning'
>>> x.split()
['hello', 'siva', 'krishna', 'good', 'morning']
>>> x.split(" ")
['hello', 'siva', 'krishna', 'good', 'morning']

ex2:
----
>>> y="hello,siva krishna,good morning"
>>> y
'hello,siva krishna,good morning'
>>> y.split(",")
['hello', 'siva krishna', 'good morning']
>>> y
'hello,siva krishna,good morning'
>>> y.split()
['hello,siva', 'krishna,good', 'morning']

ex3:
----
>>> z="hello siva krishna good morning"
>>> z
'hello siva krishna good morning'
>>> z.split(",")
['hello siva krishna good morning']
>>> z.split(" ")
['hello', 'siva', 'krishna', 'good', 'morning']
>>> z
'hello siva krishna good morning'
>>> z.split(" ",1)
['hello', 'siva krishna good morning']
>>> z.split(" ",2)
['hello', 'siva', 'krishna good morning']
>>> z.split(" ",3)
['hello', 'siva', 'krishna', 'good morning']

rsplit()
--------
Return a list of the substrings in the string, using sep as the separator string.

	strobj.rsplit(sep,maxsplit=-1)

      here sep is the separator used to split the string.

When set to None (the default value), will split on any whitespace character (including \n \r \t \f and spaces) and will discard empty strings from the result.
      
	here maxsplit is the Maximum number of splits,-1 (the default value) means no limit.

	Splitting starts at the end of the string and works to the front.

ex:
---
>>> z="hello siva krishna good morning"
>>> z
'hello siva krishna good morning'
>>> z.split(" ")
['hello', 'siva', 'krishna', 'good', 'morning']
>>> z
'hello siva krishna good morning'
>>> z.rsplit(" ")
['hello', 'siva', 'krishna', 'good', 'morning']
>>> z
'hello siva krishna good morning'
>>> z.split(" ",2)
['hello', 'siva', 'krishna good morning']
>>> z
'hello siva krishna good morning'
>>> z.rsplit(" ",2)
['hello siva krishna', 'good', 'morning']

join()
-------
Concatenate any number of strings.

The string whose method is called is inserted in between each given string.

The result is returned as a new string.

	strobj.join(iterableobj)
ex1:
----
>>> x=" "
>>> y="siva"
>>> x.join(y)
's i v a'

ex2:
----
>>> a="."
>>> b=["D","Siva"]
>>> a.join(b)
'D.Siva'

replace()
---------
Return a copy with all occurrences of substring old replaced by new.

	strobj.replace(old char/substr,new char/substr,count=-1)

     here count is the Maximum number of occurrences to replace,-1 (the default value) means replace all occurrences.

ex:
---
>>> x="hai siva krishna hai"
>>> x
'hai siva krishna hai'
>>> x.replace('i','u')
'hau suva krushna hau'
>>> x
'hai siva krishna hai'
>>> x.replace('hai','hello')
'hello siva krishna hello'
>>> x
'hai siva krishna hai'
>>> x.replace('i','u',1)
'hau siva krishna hai'
>>> x
'hai siva krishna hai'
>>> x.replace('i','u',2)
'hau suva krishna hai'
>>> x
'hai siva krishna hai'
>>> x.replace('i','u',3)
'hau suva krushna hai'
>>> x
'hai siva krishna hai'
>>> x.replace('hai','hello',1)
'hello siva krishna hai'
>>> x
'hai siva krishna hai'

ex2:
---
>>> x="hello siva krishna good morning"
>>> x.title()
'Hello Siva Krishna Good Morning'
>>> x.title().replace(' ','')
'HelloSivaKrishnaGoodMorning'
>>> ''.join(x.title().split())
'HelloSivaKrishnaGoodMorning'

startswith()
-------------
Return True if the string starts with the specified prefix, False otherwise.

	strobj.startswith(prefix,start,end)

	here start and end values optional

ex:
---
>>> x="siva krishna"
>>> x
'siva krishna'
>>> x.startswith('s')
True
>>> x.startswith('a')
False
>>> x.startswith('siv')
True
>>> x.startswith('sia')
False
>>> x.startswith('k')
False
>>> x.startswith('k',5)
True

	here start and end values are optional
