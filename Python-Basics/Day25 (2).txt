write a python program to print "*"s in Alphabet 'H' pattern?

*       *
*       *
*       *
* * * * *
*       *
*       *
*       *

	demo.py
	--------
for r in range(1,8):

        if c==1 or c==5 or r==4:

        else:

    print()

ex9:
---
write a python program to print given string in a floyd's triangle pattern?

sample input:
	
	siva

expected output:

   s
  s i
 s i v
s i v a

	demo.py
	-------
x=input("enter your string: ")
for r in range(len(x)):
    for c in range(len(x)-r-1):
        print(" ",end="")
    for c in range(r+1):
        print(x[c],end=" ")
    print()

ex10:
----
write a python program to print given string in a inverted floyd's triangle pattern?

sample input:
	
	siva

expected output:

s s s s
 i i i
  v v
   a

	demo.py
	-------
x=input("enter your string: ")
for r in range(len(x)):
    for c in range(r):
        print(" ",end="")
    for c in range(len(x)-r):
        print(x[r],end=" ")
    print()

ex11:
-----
write a python program to print given string in a pyramid pattern?

sample input:

	siva

expected output:

      a
    v a v
  i v a v i
s i v a v i s

	demo.py
	-------
x=input("enter your string: ")
for r in range(len(x)):
    
    for c in range(len(x)-r-1):
        print(" ",end=" ")
        
    for c in range(len(x)-r-1,len(x)):
        print(x[c],end=" ")
        
    for c in range(len(x)-2,len(x)-r-2,-1):
        print(x[c],end=" ")
        
    print()
