infinite while loop:
--------------------
infinite while loop means our while condition is always True.

	syntax
	------
	while condition:
		stmt_1
		stmt_2
		......
		stmt_n

flowchart:
----------
	ref fig: infinite while loop flowchart

ex1:
----
	demo.py
	-------
while True:
    print("hai")

	(or)

while 1:
    print("hai")

	(or)

while 3<5:
    print("hai")

	output
	------
hai
hai
hai
hai
hai
hai
....
...., keep on executeing upto sufficienht memory

Jumping/Transform statements:
------------------------------
the python supported Jumping/Transform statements are,

	break
	continue
	pass

break statement:
----------------
the "break" is a keyword in python, which is used in the looping statements only.

if we want to exit from the loop execution at the time of middle of the loop execution, in that case we are using "break" statement.

whenever the control reach the "break" statement then immediately the control will goto outside the while/for block i.e., the control exit from that loop.

ex2:
----
	demo.py
	--------
i=0
while True:
    print("hai",i)
    if i==5:
        break
    i+=1
print("bye")

	output
	------
hai 0
hai 1
hai 2
hai 3
hai 4
hai 5
bye

continue statement:
-------------------
the "continue" is a keyword in python,which is used in the looping statements.

if we want to skip the execution of one particular iteration, in that case we are using "continue" statement.

whenever the control reach the "continue" statement then immediately to skip the execution of that particular iteration i.e., dont execute remaining statements in our while/for block and control will goto main loop statement.

ex3:
---
	demo.py
	-------
i=0
while i<=5:
    i+=1
    if i==3:
        continue
    print("hai",i)
print("bye")

	output
	-------
hai 1
hai 2
hai 4
hai 5
hai 6
bye

pass statement:
----------------
the "pass" is a keyword in python, which is used to create a empty blocks i.e., empty if block,else block,elif block,while block,for block,function block,class block and method block in python.

	c/c++/java			Python
	---------			-------
	if(condition)			if condition:
	{					pass

	}				(or)

					if condition:
						...


function in C				Python
	-------				-------
	function funcname(p_1,..,p_n)	def funname(p_1,...,p_n):
	{					pass


	}

class in Java				Python
      --------				--------
	class classname			class classname:
	{					pass

	}
