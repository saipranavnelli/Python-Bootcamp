what is Keyword?
----------------
a keyword is a special/reserved word, these words are predefined for some special purpose, we can use that words only for that particular purpose.

python2.x versions		--> 31 keywords

python3.x(3.0 to 3.6.x)		--> 33 keywords

python3.x(3.7.0 to 3.8.x)	--> 35 keywords

python3.x(3.9.0 to 3.9.x)	--> 36 keywords

python3.x(3.10.0 to 3.14.x)	--> 35 keywords

ex1:
----
write a python program/script to print the list of all the keywords?

	list_of_keywords.py
	-------------------
import keyword
print(keyword.kwlist)

	output
	------
C:\Users\Lenovo\Desktop>python list_of_keywords.py
['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await', 'break', 'class', 'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']

----
write a python program/script to return the no.of keywords?

Note:
-----
from Python3.10 versions onwards to introduce softkeywords.

these softkeywords are used to implement the matych-case in python, it is similar to switch-case in other programming languages like C,C++,Java,....
