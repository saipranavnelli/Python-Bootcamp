if we want to display all the availabel methods of any class with syntax and dscription, in that case we are using help() function.

	syntax
	------
	help(classname)

		ex:
		---
		help(str)

	help(classname.methodname)

		ex:
		----
		help(str.upper)

	help(functionname)

		ex:
		---
		help(len)

if we want to display the list of all the available methods of any class without syntax and description, in that case we are using dir() function.

	syntax
	------
	dir(classname)

		ex:
		----
		dir(str)

	dir(modulename)

		ex:
		----
		dir(builtins)

Note:
-----
in python, by default every builtin class having 2 type's of methods, they are

	1).Dunder/Special/Magic methods

	2).Normal Methods


Dunder/Special/Magic methods:
-----------------------------
any method name which contains both prefix and suffix double underscores(__), that type of methods are called, Dunder/Special/Magic Methods.

these methods are executed automatically whenever we are performeing that particular operation.

working with str class Dunder Methods:
----------------------------------------
ex1:
----
>>> x="siva"
>>> y="krishna"
>>> x+y
'sivakrishna'
>>> x.__add__(y)
'sivakrishna'

ex2:
----
>>> x="siva"
>>> z=5
>>> x*z
'sivasivasivasivasiva'
>>> x.__mul__(z)
'sivasivasivasivasiva'

ex3:
----
>>> x="siva"
>>> y="Siva"

>>> x==y
False
>>> x.__eq__(y)
False

>>> x!=y
True
>>> x.__ne__(y)
True

>>> x<y
False
>>> x.__lt__(y)
False

>>> x<=y
False
>>> x.__le__(y)
False

>>> x>y
True
>>> x.__gt__(y)
True

>>> x>=y
True
>>> x.__ge__(y)
True

Normal Methods:
--------------
any method name which dont contains both prefix and suffix double underscores, that type of methods are called Normal Methods.

these methods are not executed automatically,whenever we are calling a method then only these methods are executed.

working with str class normal methods:
--------------------------------------
capitalize()
------------
Return a capitalized version of the string.

More specifically, make the first character have upper case and the rest lowercase.

	strobj.capitalize()

ex:
---
>>> x="hello"
>>> y="hai rama"
>>> z="good morning rama"
>>> a="123rama"
>>> b="Hello"
>>> c="Hello Rama"
>>> d="Hello RAMA"
>>> x.capitalize()
'Hello'
>>> y.capitalize()
'Hai rama'
>>> z.capitalize()
'Good morning rama'
>>> a.capitalize()
'123rama'
>>> b.capitalize()
'Hello'
>>> c.capitalize()
'Hello rama'
>>> d.capitalize()
'Hello rama'

count()
-------
Return the number of occurrences of given char/substr in the given string object.

	strobj.count(char/substr,start,end)

    	Optional arguments start and end are interpreted as in slice notation.

ex:
---
>>> x="hai siva krishna hai"
>>> x
'hai siva krishna hai'
>>> x.count('h')
3
>>> x.count('a')
4
>>> x.count('s')
2
>>> x.count('k')
1
>>> x.count('b')
0
>>> x.count('A')
0
>>> x.count("hai")
2
>>> x.count("haI")
0

center()
--------
Return a centered string of length width.

Padding is done using the specified fill character (default is a space)

	strobj.center(width,fillchar=" ")

	the fillchar must be one charecter long only

ex:
---
>>> x="siva"
>>> x
'siva'
>>> x.center(3)
'siva'
>>> x.center(9)
'   siva  '
>>> x.center(13,'@')
'@@@@@siva@@@@'
>>> x.center(13,'b')
'bbbbbsivabbbb'
>>> x.center(13,'7')
'77777siva7777'
>>> x.center(13,'ab')
TypeError: The fill character must be exactly one character long

zfill()
------
Pad a numeric string with zeros on the left, to fill a field of the given width.

The string is never truncated.

	strobj.zfill(width)

ex:
---
>>> x="siva"
>>> x
'siva'
>>> x.zfill(4)
'siva'
>>> x.zfill(9)
'00000siva'

find()
------
Return the lowest index in String where substring substr/char is found

	strobj.find(char/substr,start,end)

Optional arguments start and end are interpreted as in slice notation,Return -1 on failure.

ex:
---
>>> x="hai siva krishna hai"
>>> x
'hai siva krishna hai'
>>> x.find('a')
1
>>> x.find('s')
4
>>> x.find('hai')
0
>>> x.find('A')
-1
>>> x.find('b')
-1
>>> x.find('a',1)
1
>>> x.find('a',2)
7
>>> x.find('a',8,15)
-1
>>> x.find('a',8,16)
15
