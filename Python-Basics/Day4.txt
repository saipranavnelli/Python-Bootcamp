		Identifier's
		-------------
what is Identifier?
------------------
an Identifier is a Name, it's may be annything like either variable name,function name, class name and method name.

in python, at the time of defineing a an identifiers we are follow the some rules, they are

	Rule1:
	------
	the identifiers contains alphabets(lower/upper/both),digits(0-9) and 		underscore(_) symbols only.

	Rule2:
	------
	the identifiers must begin with either Alphabets or underscore(_) symbols 		only.

			(or)

	the identifiers should not begin with digits

	Rule3:
	------
	Don't assign any keyword as an Identifier

Note:
-----
in Python, the Identifiers are Case-Sensitive because of that reason python is a Casesensitive language.

		Variables
		---------
what is variable?
----------------
a variable is a name which is referenceing to an object in the memory.

the variables are used to store the data for future reference/use.

	syntax
	------
	variablename=value

examples:
---------
>>> x=10
>>> x
10

>>> My_Name_123="siva"
>>> My_Name_123
'siva'

>>> _y=20
>>> _y
20

>>> __z=30
>>> __z
30

>>> __in__=40
>>> __in__
40

>>> 2c=67
SyntaxError: invalid decimal literal

>>> and=45
SyntaxError: invalid syntax

>>> break=89
SyntaxError: invalid syntax

>>> Break=89
>>> Break
89

if we want to assign the single value to multiple variables at a time, in that case we are using following command

	var_1=var_2=....=var_n=value

ex:
---
>>> a=b=c=10
>>> a
10
>>> b
10
>>> c
10

if we want to assign the different values to different variables at a time, in that case we are using following command

	var_1,var_2,...,var_n=val_1,val_2,...,val_n

ex:
---
>>> p,q,r=10,20,30
>>> p
10
>>> q
20
>>> r
30

if we want to assign the multiple values to single variable at a time, in that case we are using following command

	var=val_1,val_2,...,val_n

ex:
---
>>> x=10,20,30
>>> x
(10, 20, 30)
>>> x[0]
10
>>> x[1]
20
>>> x[2]
30

>>> e,f,d=5
TypeError: cannot unpack non-iterable int object

>>> e,f,d=5,6
ValueError: not enough values to unpack (expected 3, got 2)

>>> e,f,d=x
>>> e
10
>>> f
20
>>> d
30

>>> x=0
>>> x
0

>>> y=0000
>>> y
0

>>> z=10,000
>>> z
(10, 0)

>>> a=10_000
>>> a
10000

>>> a=_10000
NameError: name '_10000' is not defined

>>> a=10000_
SyntaxError: invalid decimal literal

>>> my_name="siva"
>>> my_name
'siva'

>>> my-name="siva"
SyntaxError: cannot assign to expression here. Maybe you meant '==' instead of '='?

>>> my@name="siva"
SyntaxError: cannot assign to expression here. Maybe you meant '==' instead of '='?

what is Datatype?
-----------------
a datatype defines the type of the data a variable can hold.

in Generally, the datatype's can be categorized into 2 type's, they are

	1).Static Datatype's

	2).Dynamic Datatype's

Static Datatype's:
-------------------
the programmer/developer to assign the datatype to the variables by explicitly at the time of defineing/declaring the variables, is known as a Static Datatype's Concept.

any high level programming language which support Static Datatype's concept, that type of high level programming languages are called Static Typed Languages.

	ex: C,C++,Java,.Net,Go,...

ex: in C Langauge
---
	demo.c
	-------
#include<stdio.h>
void main()
{
    int eid=101;
    char ename[40]="siva";
    float esal=30000.0;
    printf("%d %s %f",eid,ename,esal);
}

Dynamic Datatype's:
-------------------
the programmer/developer don't assign the datatype to the variables by explicitly at the time of defineing/declaring the variables but at runtime automatically to assign the datatype's to the variables based on the value of that variables,is known as a Dynamic Datatype's Concept.

any high level programming language which support dynamic datatype's concept, that type of high-level programming langauges are called Dynamically Typed Langauges.

	ex: Python,JavaScript,...

ex: in Python Programming

	demo.py
	--------
eid=101
ename="siva"
esal=30000.0
print(eid,ename,esal)

Python Datatype's:
------------------
Python is a Dynamically Typed Langauge

in Python, every datatype having it's own class.

the python supported datatype's are

	1).Number/Numerical Datatype's
		a).int
		b).float
		c).complex

	2).Boolean Datatype's

	3).Text Sequence Datatype's
		a).string

	4).Number Sequence Datatype's
		a).list
		b).tuple
		c).range
		d).xrange(only in python2.x)

	5).Set Datatype's
		a).set
		b).frozenset

	6).Mapping Datatype's
		a).dictionary

	7).Binary Sequence Datatype's
		a).bytes
		b).bytearray
		c).memoryview

	8).None Datatype's



Number/Numerical Datatype's:
---------------------------
the Number/Numerical Datatype's are used to hold/store the Numerical values.

in python, the Number/Numerical Datatype's can be categorized into 3 type's, they are

	1).Integer Number Datatype's
	2).Floating Point Number Datatype's
	3).Complex Number Datatype's


Integer Number Datatype's:
--------------------------
in python, the Integer Number Datatype's having 'int' class

ex:
---
>>> x=10
>>> print(x)
10
>>> print(type(x))
<class 'int'>
>>> type(x)
<class 'int'>

in python, we can assign any number system as an integer object.

	Binary Number System's			--> 0b
	Octal Number System's			--> 0o
	Decimal Number System's
	Hexadecimal Number System's		--> 0x

ex:
---
>>> x=0b1010 #binary
>>> type(x)
<class 'int'>

>>> y=0o37 #octal
>>> type(y)
<class 'int'>

>>> z=39 #decimal
>>> type(z)
<class 'int'>

>>> p=0x2c #hexadecimal
>>> type(p)
<class 'int'>

note:
-----
int()		--> to convert any type of data into integer
		--> by default return value is 0

ex:
---
>>> x=int()
>>> x

>>> type(x)
