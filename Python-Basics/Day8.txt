the string object supporting slicing concept also.

by using slicing concept,we can retreive/fetch substrings i.e., one or more charecters from the string object at a time.

	Scenario-1
	----------
	strobj[:stop]

	here the stop/end index is exclusive value
	     by default startswith 0
	     by default increment by 1

ex:
---
>>> x="siva krishna"
>>> x[:4]
'siva'
>>> x[:-8]
'siva'

	Scenario-2
	----------
	strobj[start: ]

	here the start index is Inclusive Value
	     by default increment by 1

ex:
---
>>> x="siva krishna"
>>> x[5:]
'krishna'
>>> x[-7:]
'krishna'

	Scenario-3
	--------
	strobj[start:stop]

	here start index is Inclusive value
	     stop/end index is Exclusive value
	     by default increment by 1

ex:
---
>>> x="siva krishna"
>>> x
'siva krishna'
>>> x[5:10]
'krish'
>>> x[-7:-2]
'krish'
>>> x[5:-2]
'krish'
>>> x[-7:10]
'krish'
>>> x[3:6]
'a k'
>>> x[-9:-6]
'a k'
>>> x[4] #indexing
' '
>>> x[4:5] #slicing
' '

Note:
-----
	strobj[start:stop:step], here we are not passing any start,stop and step value, in that case our string is printed from left to right and incremented by 1 i.e., our original string exactly printed.

>>> y="siva"
>>> y
'siva'

>>> y[::]
'siva'

>>> y[ : : ]
'siva'

>>> y[ : :1]
'siva'

	strobj[start:stop:step], here we are not passing both start and stop values but we are passing step value is -1, in that case our string is printed from right to left and decremented by i.e., our string is printed in reverese order.

>>> y="siva"
>>> y[::-1]
'avis'

ex:
---
>>> x="siva krishna"
>>> x[::2]
'sv rsn'
>>> x[::-2]
'ahikai'
>>> x[5:10:2]
'kih'
>>> x[-3:-8:-2]
'hik'
>>> x[9:4:-2]
'hik'
>>> x[1:-1]
'iva krishn'

ord()
-----
to return the ASCII(American Standard Code for Information and Interchange) value of the Given Charecter.

	ord(char)

Note:
-----
	a - z	--> 97 - 122
	A - Z	--> 65 - 90
        0 - 9	--> 48 - 57

ex:
---
>>> ord('a')
97
>>> ord('9')
57
>>> ord('A')
65
>>> ord('@')
64
>>> ord('#')
35
>>> ord('ab')
TypeError: ord() expected a character, but string of length 2 found

sorted()
-------
to return the elements/charecters in sorting order from the given iterable object.

by default, the sorted() always to return the output as list format

by default, the sorted() to return the output in the form as Ascending Order.

	sorted(iterableobj,key=function,reverse=False)

ex1: Ascending Order
---
>>> x="Hello@123"
>>> y=[6,3,7,9]
>>> z=987
>>> sorted(x)
['1', '2', '3', '@', 'H', 'e', 'l', 'l', 'o']
>>> sorted(y)
[3, 6, 7, 9]
>>> sorted(z)
TypeError: 'int' object is not iterable

ex2: Descending Order
----
>>> x="Hello@123"
>>> y=[6,3,7,9]
>>> sorted(x,reverse=True)
['o', 'l', 'l', 'e', 'H', '@', '3', '2', '1']
>>> sorted(y,reverse=True)
[9, 7, 6, 3]

ex3:
----
>>> b=[10,20,30,10,20,40,10,30,10,20]
>>> sorted(b)
[10, 10, 10, 10, 20, 20, 20, 30, 30, 40]
>>> sorted(b,key=b.count)
[40, 30, 30, 20, 20, 20, 10, 10, 10, 10]
>>> sorted(b,key=b.count,reverse=True)
[10, 10, 10, 10, 20, 20, 20, 30, 30, 40]
