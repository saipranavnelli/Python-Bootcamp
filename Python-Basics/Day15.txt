eval()
------
to read one or more input values with homogenious and hetrogenious from user input.

in eval(), our input values must be seperated by "," only.

ex1:
----
	demo.py
	-------
a,b,c=eval(input("enter a,b,c values: "))
total=a+b+c
avg=total/3
print(avg)

	output1
	-------
enter a,b,c values: 4,2,5
3.6666666666666665

	output
	-------
enter a,b,c values: 4,2.3,2+3j
(2.766666666666667+1j)

	output3
	-------
enter a,b,c values: 4 2 5
SyntaxError: invalid syntax

Nested if:
----------
we can define a if block inside another if block, is known as a nested if.

	syntax
	-------
	if condition: #outer if
		stmt_1
		stmt_2
		......
		if condition: #inner if
			stmt_1
			stmt_2
			......

Note:
-----
whenever our outer if condition is True then only the control will goto inner if condition otherwise the control dont goto the inner if condition.

write a python program to check whether given two strings are Anagram strings or not?

An anagram string is a string that is formed by rearranging the letters of another string, using all the original letters exactly once. 

For two strings to be anagrams, they must contain the same characters with the same frequency

Key characteristics:
---------------------
They have the exact same set of characters.

Each character appears the same number of times in both strings.

The order of the characters is different.

Examples:
---------
"triangle" and "integral" are anagrams.

"race" and "care" are anagrams.

"debit card" and "bad credit" are anagrams if spaces are ignored.

"silent" and "listen" are anagrams

"heart" and "earth" are  anagrams

"mom" and "mam" are not an anagrams

"dad" and "bad" are not an anagrams

"mad" and "madam" are not an anagrams

	demo.py
	-------
s1=input("enter string_1: ")
s2=input("enter string_2: ")
if len(s1)==len(s2):
    if sorted(s1)==sorted(s2):
        print("Given two strings are Anagram strings")
    else:
        print("Given two strings are not an Anagram strings")
else:
    print("Given two strings are not an Anagram strings")
