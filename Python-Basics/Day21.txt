xrange()
--------
xrange() is a one builtin function in python2.x versions.

it support only python2.x versions.

the xrange() to return the xrange object, the xrange object is a immutable object.

	scenario-1
	----------
	xrange(stop)

	here the stop value is exclusive value
	     by default startswith 0
	     by default increment by 1

	
	scenario-2
	------------
	xrange(start,stop)

	here the start value is inclusive value
	     the stop value is exclusive value
	     by default increment by 1

	scenario-3
	----------
	xrange(start,stop,step)

	here the start value is inclusive value
	     the stop value is exclusive value
	     the step value is either increment or decrement
