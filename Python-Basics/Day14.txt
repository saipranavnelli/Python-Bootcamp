if block
--------
we can define any block which is preceeded by 'if' keyword, that block is called 
if block.

	syntax
	-------
	if condition:stmt

		(or)

	if condition:
		stmt_1
		stmt_2
		......
		stmt_n

		(or)

	if(condition):
		stmt_1
		stmt_2
		......
		stmt_n

----
	demo.py
	-------
print("hai")

if else block
-------------
	syntax
	-------
	if condition:
		stmt_1
		stmt_2
		......
		stmt_n
	else:
	     stmt_1
	     stmt_2
	     ......
	     stmt_n

		stmt_1
		stmt_2
		......
		stmt_n

		stmt_1
		stmt_2
		......
		stmt_n

             stmt_1
	     stmt_2

write a python script/program to check whether given integer is either positive or negative or zero?

	demo.py
	-------

    print("Positive Integer")
elif num<0:
    print("Negative Integer")

    print("Zero")

	(or)

      "Negative Integer" if num<0 else "Zero")

Positive Integer

Negative Integer

elif ladder:
-----------
we can define a single if with multiple elif blocks, is known as a elif ladder.

	syntax
	-------
	if condition:
		stmt_1
		stmt_2
		......
	elif condition:
		stmt_1
		stmt_2
		......
	elif condition:
		stmt_1
		stmt_2
		......
	---------
	---------
	---------
	elif condition:
		stmt_1
		stmt_2
		......
	else:
	    stmt_1
	    stmt_2
	    ......
Note:
----
in elif ladder, the else block is an optional.
