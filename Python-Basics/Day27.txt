working with list class methods:
--------------------------------
if we want to display all the available list class method names with syntax and description, in that case we are using help() function.

	help(list)

if we want to display the list of all the available methodnames of list class without syntax and description, in that case we are using dir() function.

	dir(list)

examples of list class normal methods:
---------------------------------------
append()
-------
Append object to the end of the list.

	listobj.append(object/value/element)

ex:
---
>>> x=[5,3.2,4j,False]
>>> x
[5, 3.2, 4j, False]
>>> x.append(9)
>>> x
[5, 3.2, 4j, False, 9]
>>> x.append("siva")
>>> x
[5, 3.2, 4j, False, 9, 'siva']
>>> x.append((6,7))
>>> x
[5, 3.2, 4j, False, 9, 'siva', (6, 7)]

clear()
-------
Remove all items from list.

	listobj.clear()

ex:
---
>>> x=[5,3.2,4j,False]
>>> x
[5, 3.2, 4j, False]
>>> len(x)
4
>>> x.clear()
>>> x
[]
>>> len(x)
0

copy()
------
Return a shallow copy of the list.

	listobj.copy()

ex:
--
>>> x=[5,3.2,4j,False]
>>> y=x #hard copy
>>> z=x.copy() #shallow copy
>>> x
[5, 3.2, 4j, False]
>>> y
[5, 3.2, 4j, False]
>>> z
[5, 3.2, 4j, False]
>>> id(x)
1655236639744
>>> id(y)
1655236639744
>>> id(z)
1655236639808

count()
-------
Return number of occurrences of value.

	listobj.count(value/element)

ex:
---
>>> x=[10,20,30,10,30,20,10,40,30,10,20,30,10]
>>> x
[10, 20, 30, 10, 30, 20, 10, 40, 30, 10, 20, 30, 10]
>>> x.count(10)
5
>>> x.count(20)
3
>>> x.count(30)
4
>>> x.count(40)
1
>>> x.count(50)
0

extend()
-------
Extend list by appending elements from the iterable.

	listobj.extend(iterableobj)

ex:
---
>>> x=[1,2,3]
>>> y=[4,5,6]
>>> x+y #concatanation
[1, 2, 3, 4, 5, 6]
>>> x
[1, 2, 3]
>>> y
[4, 5, 6]
>>> x.append(y) #appending
>>> x
[1, 2, 3, [4, 5, 6]]
>>> y
[4, 5, 6]
>>> a=[1,2,3]
>>> b=[4,5,6]
>>> a.extend(b) #extending
>>> a
[1, 2, 3, 4, 5, 6]
>>> b
[4, 5, 6]

index()
-------
Return first index of value.

Raises ValueError if the value is not present.

	listobj.index(element,start,end)

	whenever we are passing start and end value in that case it will works like as a slicing notation.

ex1:
----
>>> x=[10,20,30,40,50]
>>> x
[10, 20, 30, 40, 50]
>>> x.index(10)
0
>>> x.index(40)
3
>>> x.index(60)
ValueError: list.index(x): x not in list i.e., 60 not in list

ex2:
----
>>> y=[10,20,30,10,30,20,10,40,30,20,10]
>>> y
[10, 20, 30, 10, 30, 20, 10, 40, 30, 20, 10]
>>> y.index(10)
0
>>> y.index(30)
2
>>> y.index(10,1)
3
>>> y.index(10,4)
6
>>> y.index(10,4,6)
ValueError: list.index(x): x not in list
>>> y.index(10,4,7)
6
