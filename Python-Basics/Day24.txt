write a python program to print lowercase alphabets in a square pattern?

sample input:

	num=5

expected output:

a b c d e
a b c d e
a b c d e
a b c d e
a b c d e

	demo.py
	-------

ex10:
-----
write a python program to print lowercase alphabets in a pyramid pattern?

sample input:

	num=5

expected output:
 
        e
      d e d
    c d e d c
  b c d e d c b
a b c d e d c b a

	demo.py
	-------
num=int(input("enter your number: "))
for r in range(num):
    for c in range(num-r-1):
        print(" ",end=" ")
    for c in range(r,-1,-1):
        print(chr(97+num-c-1),end=" ")
    for c in range(r):
        print(chr(97+num-c-2),end=" ")
    print()
