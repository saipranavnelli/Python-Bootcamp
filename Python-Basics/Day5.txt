Boolean Datatype:
------------------
the Boolean datatypes are used to store the boolean values.

in python, the boolean values are True and False

in python, the boolean datatype having 'bool' class

ex:
---
>>> x=True
>>> x
True
>>> type(x)
<class 'bool'>

>>> y=False
>>> y
False
>>> type(y)
<class 'bool'>

>>> z=true
NameError: name 'true' is not defined. Did you mean: 'True'?

>>> a=false
NameError: name 'false' is not defined. Did you mean: 'False'?

note:
-----
bool()		--> to convert any type of data into boolean datatype
		--> by default return value is False

ex:
---
>>> x=bool()
>>> x

ex2:
----
>>> x=1
>>> y=0
>>> z=9

ex3:
----

>>> z=9.5

ex4:
----

>>> b=0.0j

String Datatype:
----------------
in python, the string datatype having 'str' class

in python, we can represent the string object by using '' or ""

in python, the string object is a Sequence Object i.e., insertion order is preserved in all the cases

in python, the string object is a Iterable Object i.e., we can apply the iterations

in python, the string object is a Immutable Object i.e., we can't modify the data

ex:
---
>>> x='siva'
>>> x
'siva'
>>> type(x)
<class 'str'>

>>> y="krishna"
>>> y
'krishna'
>>> type(y)
<class 'str'>

list datatype:
---------------
in python, the list datatype having 'list' class

we can create a list object by using [] or by calling list() function

in python, the list object is a Sequence Object i.e., insertion order is preserved in all the cases

in python, the list object is a Iterable Object i.e., we can apply the iterations

in python, the list object is a Mutable Object i.e., we can modify the data

ex:
---
>>> x=[]
>>> x
[]
>>> type(x)
<class 'list'>

>>> y=list()
>>> y
[]
>>> type(y)
<class 'list'>

>>> a=[4,3,7,9]
>>> a
[4, 3, 7, 9]
>>> type(a)
<class 'list'>
>>> id(a)
1433461537536
>>> a[1]=30
>>> a
[4, 30, 7, 9]
>>> id(a)
1433461537536

set datatype:
-------------
in python, the set datatype having 'set' class

we can create a set object by using {} or by calling set() function

in python, the set object is a Non-Sequence Object i.e., insertion order is not preserved in all the cases

in python, the set object is a Iterable Object i.e., we can apply the iterations

in python, the set object is a mutable Object i.e., we can modify the data

ex:
---
>>> x={}
>>> x
{}
>>> type(x)
<class 'dict'>

>>> y=set()
>>> y
set()
>>> type(y)
<class 'set'>

>>> z={5,3,7,9}
>>> z
{9, 3, 5, 7}
>>> type(z)
<class 'set'>

>>> a={1,2,3,4}
>>> a
{1, 2, 3, 4}
>>> type(a)
<class 'set'>

frozenset datatype:
--------------------
in python, the frozenset datatype having 'frozenset' class

we can create a frozenset object by calling frozenset() function

in python, the frozenset object is a Non-Sequence Object i.e., insertion order is not preserved in all the cases

in python, the frozenset object is a Iterable Object i.e., we can apply the iterations

in python, the frozenset object is a Immutable Object i.e., we can't modify the data

ex:
---
>>> x=frozenset()
>>> x
frozenset()
>>> type(x)
<class 'frozenset'>

>>> y=frozenset([6,3,7,9])
>>> y
frozenset({9, 3, 6, 7})
>>> type(y)
<class 'frozenset'>

Note:
-----
list()		--> to convert any type of iterable object into list
		--> by default return value is empty list i.e., []

tuple()		--> to convert any type of iterable object into tuple
		--> by default return value is empty tuple i.e.,()

set()		--> to convert any type of iterable object into set
		--> by default return value is empty set i.e., set()

frozenset()	--> to convert any type of iterable object into frozenset
		--> by default return value is empty frozenset i.e., frozenset()


ex1:
----
>>> x="siva"
>>> list(x)
['s', 'i', 'v', 'a']
>>> tuple(x)
('s', 'i', 'v', 'a')
>>> set(x)
{'v', 's', 'a', 'i'}
>>> frozenset(x)
frozenset({'v', 's', 'a', 'i'})

ex2:
----
>>> y=[5,3,7,9]
>>> str(y)
'[5, 3, 7, 9]'
>>> tuple(y)
(5, 3, 7, 9)
>>> set(y)
{9, 3, 5, 7}
>>> frozenset(y)
frozenset({9, 3, 5, 7})

ex3:
----
>>> z=(5,3,7,12)
>>> str(z)
'(5, 3, 7, 12)'
>>> list(z)
[5, 3, 7, 12]
>>> set(z)
{3, 12, 5, 7}
>>> frozenset(z)
frozenset({3, 12, 5, 7})

ex4:
-----
>>> a={6,3,7,12}
>>> str(a)
'{3, 12, 6, 7}'
>>> list(a)
[3, 12, 6, 7]
>>> tuple(a)
(3, 12, 6, 7)

ex5:

Dictionary Datatype:
-------------------
in python, the dictionary datatype having 'dict' class

we can create a dict object by using {} or by calling dict()

the dict object contains group of key-value pairs, each key-value pair act as one item in our dict object.

	{key:value,key:value,.....,key:value}
	 ---------,---------,.....,---------
	    |	      |               |
	item_1     item_2           item_n

in python, the dict object is a mutable object but key's must be immutable objects and values are either mutable or immutable objects.

from python3.4 versions onwards, the dict object act as a sequence object.

in python, the dict object is a iterable object.

ex:
----
>>> x={'name':'siva','age':34,'sal':30000.0}
>>> x
{'name': 'siva', 'age': 34, 'sal': 30000.0}
>>> type(x)
<class 'dict'>

None Datatype:
--------------
in python, the None Datatype having "NoneType" class

ex:
---
>>> x=None
>>> print(x)
None
>>> print(type(x))
<class 'NoneType'>

e={6,2,7,9}

print(z,type(z),id(z))
