Types of Arguments:
------------------
1).Normal Argument's
	a).Based on Function Definition
		i).non-default parameters/Arguments
	       ii).default parameters/Arguments

	b).Based on Function Calling
		i).non-keyword arguments
	       ii).keyword arguments

2).Arbitrary Argument's

3).Variable-Keyword Argument's/KW-Args

non-default parameters/Arguments:
--------------------------------
	the programmer/developer dont assign the values to the parameters at the time of function definition, that type of arguments are called non-default parameters/Arguments.

ex:
---
	demo.py
	-------
def add(x,y): #here x and y are non-default arguments
    z=x+y
    print(z)
add(4,5)

	output
	------
9

default parameters/Arguments:
-----------------------------
	the programmer/developer to assign the values to the parameters at the time of function definition, that type of arguments are called default parameters/Arguments.

ex:
---
	demo.py
	-------
def add(x=1,y=2): #here x and y are default arguments/parameters
    z=x+y
    print(z)
add(4,5) #4+5=9
add(4) #4+2=6
add() #1+2=3


	output
	-------
9
6
3

mixing of both non-default and default arguments:
-------------------------------------------------
ex:
---
	demo.py
	--------
def add(x,y=2): #here x is non-default and y is a default arguments/parameters
    z=x+y
    print(z)
add(4,5)#4+5=9
add(4)#4+2=6

	output
	------
9
6

mixing of both default and non-default arguments
-------------------------------------------------
ex:
---
	demo.py
	-------
def add(x=1,y): #here x is default and y is a non-default arguments/parameters
    z=x+y
    print(z)
add(4,5)#4+5=9


SyntaxError: Parameter without default(non-default argument) follows Parameter with default(default argument)

Note:
----
the Non-Default arguments never dont follow the Default Arguments

non-keyword arguments:
----------------------
the programmer/developer dont assign the parameters to the arguments at the time of function calling, that type of arguments are called non-keyword arguments.

the non-keyword arguments are also called positional arguments.

ex:
---
	demo.py
	-------
def msg(x,y):
    print(x,"Siva",y)
msg("Hello","Good Afternoon")
msg("Good Afternoon","Hello")

	output
	------
Hello Siva Good Afternoon
Good Afternoon Siva Hello

Keyword Arguments:
------------------
the programmer/developer to assign the parameters to the arguments at the time of function calling, that type of arguments are called keyword arguments.

ex:
---
	demo.py
	-------
def msg(x,y):
    print(x,"Siva",y)
msg(x="Hello",y="Good Afternoon")
msg(y="Good Afternoon",x="Hello")

	output
	------
Hello Siva Good Afternoon
Hello Siva Good Afternoon


mixing of both non-keyword and keyword arguments:
--------------------------------------------------
ex:
---
	demo.py
	-------
def msg(x,y):
    print(x,"Siva",y)
msg("Hello",y="Good Afternoon")

	output
	------
Hello Siva Good Afternoon

mixing of both keyword and non-keyword arguments:
--------------------------------------------------

ex:
---
	demo.py
	-------
def msg(x,y):
    print(x,"Siva",y)
msg(x="Hello","Good Afternoon")

SyntaxError: Positional(Non-Keyword) Arguments follows Keyword Arguments

Note:
----
the Non-Keyword(Positional) Arguments Never Dont follow the Keyword arguments.


the normal arguments takes exactly one value at a time.

ex1:
---
	demo.py
	-------
def f1(x):
    print(x)
f1()

	output
	------
TypeError: f1() missing 1 required positional argument: 'x'

ex2:
---
	demo.py
	-------
def f1(x):
    print(x)
f1(4,5)

	output
	------
TypeError: f1() takes 1 positional argument but 2 were given

ex3:
---
	demo.py
	-------
def f1(x):
    print(x)
f1(4)

	output
	------
4


the normal argument type is depends on the value of that argument.

ex:
---
	demo.py
	-------
def f1(x):
    print(x,type(x))
f1(4)
f1(2.3)
f1(2+3j)
f1(True)
f1("siva")
f1([6,3,7,9])
f1((6,3,7,9))
f1({5,3,7,9})
f1(frozenset("krishna"))
f1({'m':56,'sc':56,'so':21})
f1(None)

	output
	-------
4 <class 'int'>
2.3 <class 'float'>
(2+3j) <class 'complex'>
True <class 'bool'>
siva <class 'str'>
[6, 3, 7, 9] <class 'list'>
(6, 3, 7, 9) <class 'tuple'>
{9, 3, 5, 7} <class 'set'>
frozenset({'k', 'i', 's', 'n', 'a', 'r', 'h'}) <class 'frozenset'>
{'m': 56, 'sc': 56, 'so': 21} <class 'dict'>
None <class 'NoneType'>

Arbitrary Arguments:
--------------------
the Arbitrary Arguments takes 0 or more values.

by default, the Arbitrary Arguments type is tuple.

	syntax
	------
	def functionname(*parameter):
		--------
		--------
		--------

ex1:
---
	demo.py
	-------
def f1(*x):
    print(x,type(x))
f1()

	output
	------
() <class 'tuple'>

ex2:
---
	demo.py
	-------
def f1(*x):
    print(x,type(x))
f1(5)

	output
	------
(5,) <class 'tuple'>

ex3:
---
	demo.py
	-------
def f1(*x):
    print(x,type(x))
f1(4,5,9)

	output
	------
(4, 5, 9) <class 'tuple'>

ex4:
----
	demo.py
	-------
def f1(*x):
    print(x,type(x))
f1(2.3,4j,False,9,(5,6),"siva",[7,8])

	output
	------
(2.3, 4j, False, 9, (5, 6), 'siva', [7, 8]) <class 'tuple'>
