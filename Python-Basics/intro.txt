what is Programming Language?
-----------------------------
a language is a set of instructions to intend the computer or machine per formeing a one task, is known as a Programming Language.

Levels of Programming Languages:
--------------------------------
the Programming Langauges can be categorized into 2 levels, they are

	1).Low Level Programming Languags

	2).High Level Programming Languages

Low Level Programming Languags:
-------------------------------
any programming language instructions are directly understanding by the Processor, that type of programming languages are called Low Level Programming Languags.

	ex: 8086,8051,8085

High Level Programming Languages:
----------------------------------
any programming Language instructions are directly understanding by the Human-Being's, that type of programming languages are called High Level Programming Languages.

	ex: C,C++,Python,Java,.Net,Go lang,Rust,PHP,Ruby,JavaScript,Perl,
	    Modula1,Modula2,Modula3,.....

types of High Level Programming Languages:
-------------------------------------------
the High Level Programming Langauges can be categorized into 4 type's, they are

	1).Procedure Oriented Programming Languages(POPL)

	2).Object Oriented Programming Languages(OOPL)

	3).Scripting Programming Languages(SPL)

	4).Modular Programming Languages(MPL)

Procedure Oriented Programming Languages(POPL)
-----------------------------------------------
	Any High Level Programming Language which support Function's concept, that type of High Level Programming Languages are called Procedure Oriented Programming Languages(POPL).

	ex: C,Python

Object Oriented Programming Languages(OOPL):
---------------------------------------------
	Any High Level Programming Language which support OOP's concepts, that type of High Level Programming Languages are called Object Oriented Programming Languages(OOPL).

	ex: C++,Python,Java,.Net,....


Scripting Programming Languages(SPL)
-------------------------------------
	any High Level Programming Language which support Dynamic Data Type's and Interpreter Concept's, That type of High Level Programming Languages are called Scripting Programming Languages.

	ex: Python,JavaScript,Perl,Ruby,Shell-Scripting,...

Modular Programming Languages(MPL):
-----------------------------------
	any High Level Programming Language which support Module's concept, that type of High Level Programming Languages are called Modular Programming Languages(MPL).

	ex: Modula1,Modula2,Modula3,Python

what is Datatype?
----------------
to represent the type of the data.

in Generally, the datatype can be categorized into 2 type's, they are

	1).Static Datatype's

	2).Dynamic Datatype's

Static Datatype's:
-------------------
the programmer/developer to assign the datatype to the variables by explicitly at the time of declaring the variables, is known static datatype's concept.

any high level programming language which support static datatype's concept, that type of high level programming languages are called Static Typed Languages.

	ex: C,C++,Java,.Net,Go lang,....

example in C programming
-------
	demo.c
	-------
#include<stdio.h>
void main()
{
   int eid=101;
   char ename[40]="siva";
   float esal=30000.0;
   printf("%d %s %f",eid,ename,esal);
}

Dynamic Datatype's:
--------------------
the programmer/developer dont assign the datatype to the variables by explicitly at the time of declaring the variables but at run time automatically to assign the datatype to the variables based on the value of that variables, is known as a dynamic datatype's concept.

any high level programming language which support dynamic datatype's concept, that type of high level programming languages are called Dynamically Typed Languages.

	ex: Python,JavaScript

example in Python Programming
-------
	demo.py
	--------
eid=101
ename="siva"
esal=30000.0
print(eid,ename,esal)

what is Compiler?
------------------
a Compiler is a predefined program, to convert High Level(Human Readable format) into Low Level(Machine Understandable format) code.

the comipler takes entire/whole/complete source code as a input at a time and converting into machine code.

any high level programming language which support compiler that type of high level programming languages are called Compiled Programming Languages.

	ex: C,C++,Java,.Net,Go lang,...

what is Interpreter?
--------------------
an Interpreter is a predefined program, to convert High Level(Human Readable format) into Low Level(Machine Understandable format) code.

the Interpreter takes the input as statement by statement from source code and converting into machine code.

any high level programming language which support Interpreter concept, that type of high level programming languages are called Interpreted Languages.

	ex: Python,JavaScript,Perl,Ruby,Shell-Scripting,...

what is Garbage Collector?
--------------------------
the Garbage Collector is a one predefined program to perform the Automatic Garbage Collection i.e., automatically to deallocate the memory space for unused/unreferenced objects.

once Garbage Collector is executed more memory space is available so that the rest of the program execution become fast.

any high level programming language which support Garbage Collector concept, that type of High Level Programming Languages are called Garbage Collected Languages.

	ex: Java,Python,.Net,Go Lang,....
