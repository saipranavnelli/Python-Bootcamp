finditer()
----------
to return the matching object for each match in the given string object.

if there's no match, the finditer() to return the empty object i.e., don't return anything.

	finditer(pattern,string,flags=0)

ex22:
----
	demo.py
	-------
import re
match_objs=re.finditer(r"hello","hello siva Hello krishna hello rama")
for match_obj in match_objs:
    print(match_obj)

	output
	-------
<re.Match object; span=(0, 5), match='hello'>
<re.Match object; span=(25, 30), match='hello'>

sub()
------
the sub() is used to search for pattern, if pattern is matching to replace with another pattern otherwise don't replace the pattern.

	sub(pattern,repl_pattern,string)

ex26:
----
	demo.py
	-------
import re
print(re.sub(r"hello",r"hai","hello siva Hello krishna hello rama"))

	output
	------
hai siva Hello krishna hai rama

split()
-------
to split the string into list of words based on the given pattern.

	split(pattern,string)

ex28:
-----
	demo.py
	-------
import re
print(re.split(r"[\s.,:]+","hello siva,Hello.krishna:hello rama"))

	output
	-------
['hello', 'siva', 'Hello', 'krishna', 'hello', 'rama']
