Property Decorator:
-------------------
The @property decorator in Python is used to create managed attributes in classes — allowing you to define getter, setter, and deleter methods while still accessing them like normal attributes.

It’s a way to implement encapsulation without changing the attribute access syntax.


How It Works:
------------
@property
	Turns a method into a getter for a read-only attribute.

@<property_name>.setter
	Defines a setter method for assigning values.

@<property_name>.deleter
	Defines a deleter method for deleting the attribute.

Advantages:
-----------
Encapsulation: Control access to internal data.
Validation: Add checks before setting values.
Backward Compatibility: Change implementation without changing the interface.

	demo.py
	-------
class Home:
    def __init__(self,price):
        self._price=price

    @property
    def cost(self):
        return f"{self._price}"

    @cost.setter
    def cost(self,price):
        if price>0:
            self._price=price
            print("Updtaed Price Successfully")
        else:
            print("Not Updated")

    @cost.deleter
    def cost(self):
        del self._price

h=Home(4000000)
print(h.cost)
h.cost=5000000
print(h.cost)
del h.cost
print(h.cost) #error

	output
	-------

Updtaed Price Successfully

dataclass:
-----------
A dataclass in Python is a decorator that simplifies the creation of classes by automatically generating special methods like __init__, __repr__, __str__, and __eq__.

It is particularly useful for classes that primarily store data.

Key Features:
-------------
Automatic Method Generation: The @dataclass decorator generates methods like __init__, __repr__,__str__ and __eq__ automatically.

Type Annotations: Fields are defined using type hints, making the code more readable and maintainable.

Default Values: You can assign default values to fields

class Student:
    def __init__(self,sid,sname,sadd,sfee=0):
        self.sid=sid
        self.sname=sname
        self.sadd=sadd
        self.sfee=sfee

    def __str__(self):
        return f"Student Id:{self.sid},Student Name:{self.sname},\
Student Address: {self.sadd},Student Fee:{self.sfee}"

    def __eq__(self,others):
        if self.sid==others.sid:
            if self.sname==others.name:
                if self.sadd==others.sadd:
                    if self.sfee==others.sfee:
                        return True
                    else:
                        return False
                else:
                    return False
            else:
                return False
        else:
            return False
                    
        

s1=Student(101,'siva','hyd',5000)
