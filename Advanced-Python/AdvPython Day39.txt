how to filter the data?
-----------------------
When finding documents in a collection, you can filter the result by using a query object.

The first argument of the find() method is a query object, and is used to limit the search.

ex10:
----
	demo.py
	-------
import pymongo
mongo_client_obj=pymongo.MongoClient("mongodb://localhost:27017")
dbobj=mongo_client_obj["employe"]
coll_obj=dbobj["emp"]
for doc in coll_obj.find({"esal":4000},{"_id":0}):
    print(doc)

	output
	------
{'eid': 104, 'ename': 'sachin', 'esal': 4000, 'dno': 10}

Filter With Regular Expressions:
--------------------------------
You can also use regular expressions as a modifier.

Regular expressions can only be used to query strings.


ex12:
----
write a python script to get the employe documents from the collection in a MongoDB,Which employe name starts with 's' charecter?

	demo.py
	-------
import pymongo
mongo_client_obj=pymongo.MongoClient("mongodb://localhost:27017")
dbobj=mongo_client_obj["employe"]
coll_obj=dbobj["emp"]
for doc in coll_obj.find({"ename":{"$regex":'^s'}},{"_id":0}):
    print(doc)

	output
	------
{'eid': 101, 'ename': 'siva', 'esal': 3000, 'dno': 10}
{'eid': 104, 'ename': 'sachin', 'esal': 4000, 'dno': 10}

Sort the Result:
--------------
Use the sort() method to sort the result in ascending or descending order.

The sort() method takes one parameter for "fieldname" and one parameter for "direction" (ascending is the default direction).

note:
-----
sort("fieldname", 1) #ascending
sort("filedname", -1) #descending

how to update the document in our collection?
----------------------------------------------
if we want to update the document in our collection, in that case we are using update_one() method.

The first parameter of the update_one() method is a query object defining which document to update.

Note: If the query finds more than one record, only the first occurrence is updated.

The second parameter is an object defining the new values of the document.

ex16:
-----

	demo.py
	-------
import pymongo
mongo_client_obj=pymongo.MongoClient("mongodb://localhost:27017")
dbobj=mongo_client_obj["employe"]
coll_obj=dbobj["emp"]
print("before update")
for rec in coll_obj.find({},{"_id":0}):
    print(rec)
coll_obj.update_one({"esal":{"$eq":3900}},{"$set":{"esal":5000}})
print("updated successfully")
print("after update")
for rec in coll_obj.find({},{"_id":0}):
    print(rec)

how to limit the documents from the result set?
-----------------------------------------------
if we want to limit the documents from the result set, in that case we are using limit() method.

The limit() method takes one parameter, a number defining how many documents to return.

ex18:
----
	demo.py
	-------
import pymongo
mongo_client_obj=pymongo.MongoClient("mongodb://localhost:27017")
dbobj=mongo_client_obj["employe"]
coll_obj=dbobj["emp"]
for rec in coll_obj.find({},{"_id":0}).limit(3):
    print(rec)

	output
	------
{'eid': 101, 'ename': 'siva', 'esal': 9000, 'dno': 10}
{'eid': 102, 'ename': 'rama', 'esal': 9000, 'dno': 20}
{'eid': 103, 'ename': 'krishna', 'esal': 9000, 'dno': 30}

how to delete/drop the collection in mongodb?
-----------------------------------------
if we want to delete/drop the collection in mongodb, in that case we are using drop() method.

ex22:
-----
	demo.py
	-------
import pymongo
mongo_client_obj=pymongo.MongoClient("mongodb://localhost:27017")
dbobj=mongo_client_obj["employe"]
coll_obj=dbobj["emp"]
coll_obj.drop()
print("collection deleted/droped successfully")

	output
	------
collection deleted/droped successfully

note:
----
The drop() method returns true if the collection was dropped successfully, and false if the collection does not exist.
