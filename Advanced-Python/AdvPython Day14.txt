Module Search Path:
------------------
whenever we are importing a module, then immediately our python interpreter searching for that module in the following order,

	1).Main Module Location i.e., current working directory

	2).Python Path i.e., python installation location

	3).Python Standard Library i.e., inside the Lib folder

our imported module is not available in the above 3 locations, in that case our python interpreter to raise the ModuleNotFoundError Exception.

ex1:
-----
	C:\\Python313\\siva\\wishes.py
	-----------------------------
print("hai")

	C:\\Python313\\siva\\msg.py
	---------------------------
import wishes
print("siva")

	output
	------
hai
siva

Reloading a module:
--------------------
by default, each and every module is loaded into the memory at only once.

ex:
---
	C:\\Python313\\siva\\wishes.py
	-------------------------------
print("hai")


	C:\\Python313\\siva\\msg.py
	---------------------------
import wishes
print("siva")
import wishes
print("rama")
import wishes
print("krishna")

	output
	------
hai
siva
rama
krishna

if we want reloading a module i.e., once again we are loading same module, in that case we are using reload() of importlib module

ex2:
---
	C:\\Python313\\siva\\wishes.py
	-------------------------------
print("hai")


	C:\\Python313\\siva\\msg.py
	---------------------------
import wishes
import importlib
print("siva")
importlib.reload(wishes)
print("rama")
importlib.reload(wishes)
print("krishna")

	output
	------
hai
siva
hai
rama
hai
krishna 

how to get all the available modules in  python installation location and Standrad library?

if we want to get all the available modules in python installation location and Standrad library, in that case we are using help() function.

	help("modules")

if we want to display all the properties of any module, in that case we are using dir() function.

	import modulename
	dir(modulename)

working with "builtins" module:
--------------------------------
the "builtins" module is a one builtin module in python.

if we want to display all the properties of "builtins" module, in that case we are using dir() function.

	import builtins
	dir(builtins)

without importing builtins module into our program directly we can access builtins module properties.

ex:
---
	demo.py
	-------
x=[4,3,7,9]
print(x)
print(len(x))
print(min(x))
print(sum(x))
print(sorted(x))
print(list(reversed(x)))
y=13
print(bin(y))
print(oct(y))
print(hex(y))
print(ord('a'))
print(chr(65))
print(pow(2,3))
print(round(2.4))
print(round(2.6))

	------

[9, 7, 3, 4]

Note:
-----
except Builtins module, we can access properties from any another module, in that case we need to import that module.

working with "math" module:
-----------------------------
the "math" module is a one builtin module in python.

if we want to display all the properties of "math" module, in that case we are using dir() function.

	import math
	dir(math)

if we want to working with "math" module propertiesin that case it is mandatory to import "math" module into our program.

working with "string" module
-----------------------------
the "string" module is a one builtin module in python.

if we want to display all the properties of "string" module, in that case we are using dir() function.

	import string
	dir(string)

if we want to working with "string" module properties in that case it is mandatory to import "string" module into our program.
