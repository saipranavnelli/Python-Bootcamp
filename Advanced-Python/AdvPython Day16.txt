working with "calendar" module:
-------------------------------
the "calendar" module is a one builtin module in python.

if we want to display all the properties of "calendar" module, in that case we are using dir() function.

	import calendar
	dir(calendar)

if we want to working with "calendar" module properties in that case it is mandatory to import "calendar" module into our program.

ex1:
----
	demo.py
	-------
from calendar import calendar
year=int(input("enter year: "))
print(calendar(year))

	(or)

from calendar import prcal
year=int(input("enter year: "))
prcal(year)

	demo.py
	-------

working with "datetime" module:
-------------------------------
the "datetime" module is a one builtin module in python.

if we want to display all the properties of "datetime" module, in that case we are using dir() function.

	import datetime
	dir(datetime)

if we want to working with "datetime" module properties in that case it is mandatory to import "datetime" module into our program.

ex1:
----
>>> from datetime import datetime
>>> x=datetime.now()
>>> x
datetime.datetime(2026, 5, 13, 12, 18, 33, 434067)
>>> type(x)
<class 'datetime.datetime'>
>>> x.year
2026
>>> x.month
5
>>> x.day
13
>>> x.hour
12
>>> x.minute
18
>>> x.second
33
>>> x.microsecond
434067
>>> x.ctime()
'Wed May 13 12:18:33 2026'
>>> x.min
datetime.datetime(1, 1, 1, 0, 0)
>>> x.max
datetime.datetime(9999, 12, 31, 23, 59, 59, 999999)
>>> x.strftime("%Y-%m-%d %H:%M:%S %p")
'2026-05-13 12:18:33 PM'
>>> x.timetuple().tm_yday
133
>>> x.timetuple().tm_wday
2

>>> from datetime import datetime

8
