ex10:
-----
write a python script/program to print the no.of items,no.of files and no.of directoris from the given location/path?

	demo.py
	-------
import os
os.chdir('siva')
total_items=len(os.listdir())
f_c=d_c=0
for i in os.listdir():
    if os.path.isfile(i):
        f_c+=1
    elif os.path.isdir(i):
        d_c+=1
print(f"Total No.of Items: {total_items}")
print(f"No.of Files: {f_c}")
print(f"No.of Dirs: {d_c}")
