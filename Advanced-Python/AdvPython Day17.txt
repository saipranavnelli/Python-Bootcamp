working with "random" module:
------------------------------
the "random" module is a one builtin module in python.

if we want to display all the properties of "random" module, in that case we are using dir() function.

	import random
	dir(random)

if we want to working with "random" module properties in that case it is mandatory to import "random" module into our program.
