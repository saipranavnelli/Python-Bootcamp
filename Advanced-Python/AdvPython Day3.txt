Local/Method Variables:
-----------------------
we can define a variables within the methods directly, that type of variables are called Local Variables.

we can access the Local Variables Data within that particular method only

ex:
---
	demo.py
	--------
class Test:
    x=10 #Static Variable
    def m1(self):
        self.y=20 #NonStatic Variable
        z=30 #Local Variable
        print(Test.x) #10
        print(self.y) #20
        print(z)#30
    def m2(self):
        print(Test.x) #10
        print(self.y) #20
        print(z) #Error
t1=Test()
t1.m1()
t1.m2()

	output
	------
10
20
30
10
20
NameError: name 'z' is not defined

Note:
----
whenever we are declare the non-static variables within the methods, in that case that non-static variables memory allocation is depends on no.of times we are calling a method, this is a more memory consumeing process, to overcome that problem to introduce Constructors and Initializers.

what is Constructor?
--------------------
a constructor is a one special method, the main purpose constructor is to creating an instance.

in python __new__() is a constructor.

the constructor must return the instance.

what is Initializer?
--------------------
a Initializer is a one special method, the main purpose of Initializer is to initialize the Non-static/Instance variables.

in python __init__() is a Initializer

the Initializer dont return anything i.e., return statement is not required

note:
-----
the constructor and initializer's are executed automatically at the time of creating an instance.

whenever we are trying to creating the instance internally first constructor is executed and next the initializer is executed.

ex1:
----
	demo.py
	--------
class Test:
    def __new__(self):
        print("I am in Constructor")
        return object.__new__(self)

    def __init__(self):
        print("I am in Initializer")
        
t1=Test()

	(or)

class Test:
    def __init__(self):
        print("I am in Initializer")
        
    def __new__(self):
        print("I am in Constructor")
        return object.__new__(self)   
        
t1=Test()

	output
	------
I am in Constructor
I am in Initializer

Note:
-----
with respect to one object the constructor and initializers are executed at only once but with respect to one object we can call one method N no.of times.
