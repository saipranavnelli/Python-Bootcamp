what is MRO(Method Resolution Order)?
-------------------------------------
MRO defines the order in which class are searched when executeing a method or looking for an attribute.

it is very important in multiple inheritance situations.

how to check MRO in Python?
---------------------------
we can check MRO in python by using following options,

	by calling mro()
	by using __mro__
	by using help()

ex:
---
	demo.py
	-------
class x:
    def m1(self):
        print("hello")
class y:
    def m1(self):
        print("hai")
class z(x,y):
    def m1(self):
        print("bye")

z1=z()
print(z.mro())
print("="*45)
print(z.__mro__)
print("="*45)
print(help(z))

	output
	------
[<class '__main__.z'>, <class '__main__.x'>, <class '__main__.y'>, <class 'object'>]
=============================================
(<class '__main__.z'>, <class '__main__.x'>, <class '__main__.y'>, <class 'object'>)
=============================================
Help on class z in module __main__:

class z(x, y)
   Method resolution order:
       z
       x
       y
       builtins.object

note:
-----
python uses something called C3 Linearization algorithm to determine the MRO.

python's C3 linearization ensures:
	Children come before Parents.
	if a class appears in multiple bases,it only appear once(no-duplication)
	Order Respects the declaration order of parents

what is Polymorphism?
---------------------
the Polymorphism is an Object Oriented Programming(OOP) concept that allows objects of different classes to be treated as objects of a common superclass i.e., "many forms".

in simple terms,polymorphism lets you define One Interface and have multiple implementations.

types of polymorphism in python:

1).Duck Typing(dynamic Polymorphism)
2).Method Overriding(runtime polymorphism)
3).Operator Overloading(compiletime polymorphism)

ex1:
---
let's say you have multiple ways to make a payment: credit card,Paypal,PhonePay and Bank Transfer. all of them have a method called make_payment() but behave differently.

	demo.py
	-------
class Payment:
    def make_payment(self):
        pass

class CreditCard(Payment):
    def make_payment(self):
        return "paid using Credit Card"

class PayPal(Payment):
    def make_payment(self):
        return "paid using PayPal"

class PhonePay(Payment):
    def make_payment(self):
        return "paid using PhonePay"

class BankTransfer(Payment):
    def make_payment(self):
        return "paid using Bank Transfer"

def process_payment(payment_method):
    print(payment_method.make_payment())

credit=CreditCard()
paypal=PayPal()
phonepay=PhonePay()
banktransfer=BankTransfer()

process_payment(credit)
process_payment(paypal)
process_payment(phonepay)
process_payment(banktransfer)

	output
	-------
paid using Credit Card
paid using PayPal
paid using PhonePay
paid using Bank Transfer
