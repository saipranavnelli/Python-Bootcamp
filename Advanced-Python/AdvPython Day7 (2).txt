class Book:
    def __init__(self,pages):
        self.pages=pages

    def __add__(self,others):
        return self.pages+others.pages

    def __sub__(self,others):
        return self.pages-others.pages

    def __mul__(self,others):
        return self.pages*others.pages

    def __eq__(self,others):
        if self.pages==others.pages:
            return True
        else:
            return False

    def __ne__(self,others):
        if self.pages!=others.pages:
            return True
        else:
            return False

    def __lt__(self,others):
        if self.pages<others.pages:
            return True
        else:
            return False

    def __le__(self,others):
        if self.pages<=others.pages:
            return True
        else:
            return False

    def __gt__(self,others):
        if self.pages>others.pages:
            return True
        else:
            return False

    def __ge__(self,others):
        if self.pages>=others.pages:
            return True
        else:
            return False
        

b1=Book(300)
b2=Book(200)
print(b1+b2)
print(b1-b2)
print(b1*b2)
print(b1==b2)
print(b1!=b2)
print(b1<b2)
print(b1<=b2)
print(b1>b2)
print(b1>=b2)

Access Modifiers:
------------------
In Python, access modifiers determine the visibility and accessibility of class members (variables and methods).

Unlike some other languages like Java or C++, Python doesn’t enforce strict access control, but it follows a naming convention to imply how members should be accessed.

1. Public Members(public access modifier)

Syntax: No underscore (name)

Access: Can be accessed from anywhere (inside or outside the class)

Use case: Use when you want a variable or method to be freely accessible.

Real-World Analogy: A library book's title is visible to everyone.

ex:
---
	demo.py
	-------
class Book:
    def __init__(self, title):
        self.title = title  # public non-static attribute

    def get_title(self):    # public method
        return self.title

book = Book("The Alchemist")
print(book.title)           # Accessing public non-static attribute
print(book.get_title())     # Accessing public method

	output
	------
The Alchemist
The Alchemist

2. Protected Members(protected access modifier)
Syntax: Single underscore (_name)

Access: Intended to be accessed within the class and subclasses

Use case: Suggests that it shouldn’t be accessed from outside unless absolutely necessary.

Real-World Analogy: An employee's salary — managers or HR can access it, but regular people shouldn't.

ex:
---
	demo.py
	-------
class Employee:
    def __init__(self, name, salary):
        self.name = name #public non-static attribute
        self._salary = salary  # protected non-static attribute

class Manager(Employee):
    def get_salary(self): #public method
        return self._salary  # Accessing protected member in subclass

m = Manager("Alice", 80000)
print(m.name)
print(m.get_salary())        # Allowed
print(m._salary)             # Still accessible, but not recommended

	output
	-------
Alice
80000
80000
