single try with multiple except blocks:
---------------------------------------
	try:
	   stmt_1
	   stmt_2
	   ......
	   stmt_n
	except ExceptionClassName:
	   stmt_1
	   stmt_2
	   ......
	   stmt_n
	except ExceptionClassName:
	   stmt_1
	   stmt_2
	   ......
	   stmt_n
	--------
	--------
	except ExceptionClassName:
	   stmt_1
	   stmt_2
	   ......
	   stmt_n
	except:
	    stmt_1
	    stmt_2
	    ......
	    stmt_n

note:
----
in single-try with multiple except blocks, we can define the default except block must be last.

what is Exception Class?
--------------------------
an Exception Class is a one Builtin exception class, it act as a super class of all builtin exception classes like ValueError,ZeroDivisionError,NameError,KeyError,
IndexError,....etc.,

the user-defined exception classes also should be derived from this class.
          
Nested Try:
-----------
we can define a try block inside another try block, is known as a nested try block.

	syntax
	------
	try: #outer-try
	   stmt_1
           stmt_2
	   ......
	   try: #inner-try
              stmt_1
              stmt_2
	      ......
	   except:
	      stmt_1
	      stmt_2
	      ......
	except:
	    stmt_1
	    stmt_2
	    ......

if any exception will be occured in our outer-try block, that can be handled by using outer-try-except block only, whether it is handled that except block logic will be executed otherwise our program execution will be terminates abnormally.

ex1:
----
	demo.py
	--------
print("hai")
try:
    x=int(input("enter x value: "))
    y=int(input("enter y value: "))
    try:
        z=x/y
        print(z)
    except ZeroDivisionError:
        print("sno can't be zero")
    
except ValueError:
    print("enter integers only")
print("bye")
          
output1: without exception in our outer try block
-------
hai
enter x value: 2
enter y value: 3
0.6666666666666666
bye


output2: with exception in our outer try, that can be handled by outer try except
-------
hai
enter x value: 3
enter y value: 2.3
enter integers only
bye

if any exception will be occured in our inner-try block, that can be handled by using inner-try-except block,whether it is handled in that case inner-try-except block will be executed otherwise to handle that exception by using outer-try-except block also, whether it is handled in that case outer-try-except block logic will be executed otherwise our program execution will be terminates abnormally.
