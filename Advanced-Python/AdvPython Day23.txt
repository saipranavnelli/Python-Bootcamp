what is Package?
----------------
a package is folder/directory which contains one or more python modules.

we can treat any package as a python package, that package should contains __init__.py file.

some times, a folder contains sub folder's also, we can treat that sub folder as a python package, that sub folder also contains __init__.py file.

	ref fig: package example

how to access the data from outside of that package?
-----------------------------------------------------
we can access the data from outside of that package, first we need to import that package,

	1).normal/basic importing a package
	
	2).aliasing a packagename

	3).from importing a package

	4).from importing a package with *

----------------------------
	import mainpackagename.modulename
	import mainpackagename.subpackagename.modulename

what happens when you run a .py file?
---------------------------------------
when you execute a Python File(demo.py):

step1: Python Interpreter reads .py file(your source code)

step2: Python Interpreter compiles the .py into bytecode(a lower level,platform independent representation).

step3: Bytecode is either executed immediately or saved as a .pyc files inside a __pycache__ folder

step4: Python Interpreter(specifically Python Virtual Machine(PVM)) executes the bytecode instruction by instruction.

	ref fig: python interpreter architecture

python program execution flow:
-------------------------------
	your Code(.py file)
	     |
	Parser(checks syntax)
	     |
	Compiler(translate to Byte code)
	     |
	Bytecode( .pyc in __pycache__ folder)
	     |
	Python Virtual Machine(PVM)
	      |
	Execution(Running the program and show the output)

Note:
-----
if .pyc file is already exists and is up-to-date,Python skips compiling , it directly loads the .pyc and runs it.

if source .py file has changed , python recompiles and Generates a new .pyc file.

what is Cpython?
----------------
CPython is the reference implementation of the Python programming language. Written in C and Python, CPython is the default and most widely used implementation of the Python language.

CPython can be defined as both an interpreter and a compiler as it compiles Python code into bytecode before interpreting it.

how to get python implementation?
---------------------------------
>>> import platform
>>> platform.python_implementation()
'CPython'
