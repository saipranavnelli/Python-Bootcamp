working with "sys" module:
------------------------------
the "sys" module is a one builtin module in python.

if we want to display all the properties of "sys" module, in that case we are using dir() function.

	dir(sys)

if we want to working with "sys" module properties in that case it is mandatory to import "sys" module into our program.

stdin(standard input):
---------------------
it is the default source of input(usually the keyboard)

in python, it is represented by sys.stdin

functions like input() read from stdin

stdout(standard output):
------------------------
it is the default destination for output(usually the console/terminal)

in python,print() writes to sys.stdout

stderr(standard error):
-----------------------
default stream for error messages

it is seperate from stdout so errors can be seen/logged differently

in python, it is represented by sys.stderr

why do we need them?
---------------------
stdin,stdout,stderr make programs communicate with users or other programs

they are useful in redirection:

	python script.py > output.txt	---> sends stdout to file

	python script.py 2 > error.txt	---> sends stderr to file

	python script.py < input.txt	---> takes stdin from file instead of
					     keyboard

Note:
-----
in Unix/Linux and also windows shell, every process has three default file descriptors, they are

	0	--> stdin(standard input)
	1	--> stdout(standrad output)
	2	--> stderr(standard error)

in the above shell we are using:

	1>	it is redirect to stdout
	2>	is is redirect to stderr

if you just use > without a number, it is defaults to 1> redirect to stdout


what are command line arguments?
----------------------------------
Command Line Arguments(CLAs) are inputs that you pass to a python program from the command prompt/terminal when running it.

ex:
---
	python myscript.py hello siva

here myscript.py	--> python file
     hello siva		--> command line arguments

these allows you to control the program behavior without editing the code

why use Command Line Arguments?
-------------------------------
Flexibility : you can change input without modifying the code

Automation : useful in shell-scripts,cron jobs and devops pipelines

Reusability : same program can work with different inputs

Scalability : ideal for production scripts

how to implement the command line arguments in python?
------------------------------------------------------
we can implement the command line arguments in python by using argv variable of sys module.

the argv variable always to return the list of command line arguments.

in python, our file name also will be treated as first command line argument.

through command prompt we can pass any argument by default that argument will be treated as string object.

----
write a pytho script/program to get the list of command line arguments?
