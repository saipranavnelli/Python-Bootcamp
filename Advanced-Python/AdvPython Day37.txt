for rec in cur_obj:
    print(f"Total No.of Employees: {rec[0]}")
    print(f"Minimum Salary: {rec[1]}")

working with sqlite3 database:
-------------------------------
SQLite3 is a popular lightweight, embedded relational database management system (RDBMS) often used in applications where a full-fledged database server is not needed. 

It's known for its simplicity, portability, and minimal resource requirements. 
SQLite3 is a C library that allows applications to create and manage databases directly on the file system without a separate server process. 

Python SQLite3 module is used to integrate the SQLite database with Python.
 
It is a standardized Python DBI API 2.0 and provides a straightforward and simple-to-use interface for interacting with SQLite databases. There is no need to install this module separately as it comes along with Python after the 2.5x version.

SQLite Studio is a free, open-source graphical User Interface (GUI) tool for working with SQLite databases. 

It simplifies database management, offering a user-friendly interface to create, query, and manage SQLite databases without writing extensive SQL commands. 

SQLite Studio is ideal for beginners and experienced developers like, providing features like syntax highlighting, query execution, and database visualization.

Installation of SQLite Studio

1. Download SQLite Studio: 
Visit the official SQLite Studio website: https://sqlitestudio.pl/ and download the version suitable for your operating system.

2. Extract Files: Extract the downloaded file into a directory of your choice.

3. Run SQLite Studio: Open the executable file (sqlitestudio.exe on Windows) to launch the application.
